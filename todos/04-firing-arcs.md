# 04 · 射界系统与可视化

- 优先级:P0
- 依赖:03
- GDD 参考:§4.2 射界

## 背景

射界是 P1(走位即火控)的机制载体:塔装在哪条舷,决定它朝哪射。

## 任务

- [ ] 射界计算:塔射界 = 所在格暴露边法线方向 ± 塔弧度/2(随船体朝向旋转)
- [ ] 角落格:两条暴露边法线的角平分线为中心,弧度 +60°
- [ ] 弧度档位:极窄 30° / 窄 60° / 中 100° / 广 150°(360° 全向接口预留,MVP 不用)
- [ ] 目标过滤:塔只索敌/攻击射界扇形 ∩ 射程圆内的目标
- [ ] 射界内无目标时炮管归位(回到扇形中心朝向)
- [ ] 按住 Tab:战斗中叠加显示所有塔的射界扇形

## 验收标准

- [ ] 单元测试:普通边缘格、角落格、多暴露边(凹形轮廓)三类用例的射界中心与范围正确
- [ ] Tab 可视化扇形与实际可命中区域一致(肉眼抽查 + 边界目标测试)
- [ ] 船旋转时射界实时跟随,无一帧延迟撕裂感
