# 05 · 武器塔框架与 6 种 MVP 塔

- 优先级:P0(其中机炮+电弧为 M0 灰盒最小子集)
- 依赖:03, 04
- GDD 参考:§5.1 塔属性框架、§5.2 武器塔、§5.4 塔升级、§14 数值初稿

## 背景

每座塔四要素:伤害 / 射程 / 弧度 / 节流机制。节流三选一(过热/弹药/充能)是支援设施(06)的作用锚点,必须做成三套可区分的机制。

## 任务

- [ ] 塔基类/框架:属性配置化(单独数据文件,便于调参),索敌 = 射界内**最近优先**(§17.4 的 A/B 延后)
- [ ] 节流机制 ×3:
  - **弹药**:弹夹 + 装填时间
  - **过热**:持续射击热量上升,过热强制冷却
  - **充能**:蓄力周期,满充放
- [ ] 6 种塔(除机炮外数值占位):

| 塔 | 弧度 | 节流 | 行为 |
|---|---|---|---|
| 自动机炮 | 100° | 弹药 | 直射弹。**锚点数值**:6 伤 / 2.5 发/s / 射程 380 / 弹夹 20 / 装填 1.5s |
| 激光棱镜 | 60° | 过热 | 持续单体光束,融精英 |
| 电弧塔 | 150° | 过热 | 短程链式闪电,清蜂群 |
| 磁轨炮 | 30° | 充能 | 蓄力后直线穿透 |
| 点防阵列 | 150° | 弹药 | 近防速射;拦截弹幕接口预留(MVP 4 敌均无弹幕) |
| 等离子迫击炮 | 60° | 充能 | 抛射越过前排,落点 AoE |

- [ ] 同名叠级 Lv1→Lv5:数值成长,原格生效不占新格
- [ ] (可选)Lv3/Lv5 机制小跳变(如机炮 Lv3 双管、Lv5 曳光弹)
- [ ] (可选)broadside 反馈占位:单舷 ≥3 塔同帧开火时简单屏幕反馈(shake/闪光)

## 验收标准

- [ ] 6 塔均可放置、自动索敌、开火,弹道/光束/链电/AoE 表现可区分
- [ ] 三种节流机制在 UI 上可读(弹夹数 / 热量条 / 充能环,简陋即可)
- [ ] 改数据文件即可调平衡,不改代码
- [ ] 500 弹同屏不掉帧(联 01 压测)
