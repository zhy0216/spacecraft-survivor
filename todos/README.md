## 范围定义

创新探索的诊断结论:P1(走位即火控)健在,P2 萎缩成数值堆叠,P3 只剩剪影;结构问题是每局同质、高潮全在菜单里。本批不动结构(岔路信标/满层质变/镜像 Boss 归第二三波),只做**数日粒度的微手术**:

1. **修错配**(23/27/29):起手法令三套零作用、散热与增幅 5 层复利失衡、Boss 召唤表长度失约;
2. **复活 broadside**(24):`FireSink.fired` 空通道接上齐射共振;
3. **节奏补拍**(25/26):环阵事件(名场面)+ 段落收束与磁吸涌(章节感/犒赏感),即节奏方案的 P1/P3/P4a;
4. **可发现性**(28):I / Tab 两个核心键位从零提示变有提示。

## 备注:全批共用的确定性口径

- **rng 恒量掷合同**:本批没有一条允许"按条件多掷/少掷"。25 号环阵每只仍恰好消耗
  1 次出生角 rng(值改作 ±2° 抖动),World 侧半径/side 两掷不动;24 号纯统计零 rng;
  26 号磁吸涌零 rng(计时器置位)。改波次表/压档会**移动序列**(出怪数与经验轨迹变了),
  这属于"改脚本",按先例(a231599、潮汐那轮)重钉固定 seed 用例,与"改合同"是两码事。
- **存档版本只升一次**:本批唯一动快照结构的是 26 号(磁吸涌计时器),`RUN_SAVE_VERSION`
  2→3、旧档判废(既有口径)。24 号刻意做成表现层(随 DPS 平滑先例不进 checksum),
  就是为了不陪着升版本;若后续把共振升级成真增益,再随第二波满层质变一起进 checksum。
- **经济验收账**:27 号压增幅、26 号磁吸涌都会改一局残骸总账。验收锚点仍是
  「一局 12–15 次升级」(data/economy.ts 的算账注释);跑完 economy 长跑若掉出窗口,
  优先调回数值,不许改窗口迁就。
- **潮汐铁律不破**(25 号):退潮必须绑任务、时间加权平均 mul 贴着 1(±15% 单测钉着)。
  环阵前的静场预告与突围后的退潮窗都要在这两条里做。
