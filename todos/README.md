## 范围定义

第一批跑通了 M0+M1 的完整闭环(手感/甲板/塔/敌/波次/经济/HUD/扩建/船坞)。
本批目标:**把一局从"能打"变成"想一直打"** —— 补上三块最大的爽感缺口:

1. **零反馈的耳朵**(全仓无任何音频,齐射只靠镜头顿挫);
2. **一局没有高潮与变化**(无精英、无 Boss、三选一没有重摇);
3. **局内没有复利时刻、局外没有重玩理由**(无进化配方、无法令、无元解锁)。

## 建议实施顺序

```
13 音频(独立,最快见效,半天铺满)
   ↓
14 精英 → 16 星币重摇(掉落联动闭环)
   ↓
15 Boss(给一局收个高潮)
   ↓
17 进化 → 18 法令(局内复利与卡池多样)
   ↓
19 元进度(给"再来一把"的理由)
```

## 明确不做(本批之外)

登舰机制、主动技/船级进化树(T1/T2)、星图节点选路、无尽模式、深空热度、商店节点、
手柄/手机适配、局间保存(19 号只做解锁状态,不保存局内)。

  不得为省事跳过。

  "填了就出精英"。
