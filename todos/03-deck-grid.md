# 03 · 甲板网格与放置规则

- 优先级:P0
- 依赖:01
- GDD 参考:§4.1 格子规则、§4.5 战斗中放置规则、§8(T0 拾荒艇)

## 背景

甲板 = 正交网格,唯一需要记住的规则:**边缘格开火,内部格供能**。MVP 只有 T0 拾荒艇的初始 3×4 甲板(10 个边缘格 + 2 个内部格)。

## 任务

- [ ] 3×4 甲板数据模型;格状态:空 / 武器塔 / 支援设施
- [ ] 暴露边计算:边缘格(≥1 条边暴露)、内部格(四面被围)、角落格(2 条暴露边)——按占用格集合动态推导,不写死(12 扩建复用)
- [ ] 放置合法性:武器塔仅限边缘格;支援设施任意空格(内部格只能放支援)
- [ ] 放置交互:合法格高亮,非法放置拒绝并提示
- [ ] 战斗规则:新塔只能放进**空格**;已放置的塔不可移动、不可出售(MVP 无船坞,此即全部规则)
- [ ] 塔"离线"状态机预留:格子失去暴露边 → 塔灰显、不开火(MVP 无扩建不会触发,12 需要)

## 验收标准

- [ ] 暴露边/边缘/内部/角落判定有单元测试,含非矩形占用集合的用例
- [ ] 内部格放武器塔被拒绝;边缘格放支援设施允许
- [ ] 甲板渲染与船体一同旋转,格子世界坐标随船变换正确
