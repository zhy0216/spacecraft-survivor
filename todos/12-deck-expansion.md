# 12 · 甲板拼块扩建(延伸,可砍)

- 优先级:P2 — MVP 验证目标(转向手感 + 舷向火控 + 三选一循环)不依赖本条;若周期紧可整条推迟
- 依赖:03, 04, 10
- GDD 参考:§4.4 甲板扩建、§4.1(边缘内化)、§2.1(P3 船形即成长)

## 背景

扩建是 P3(船形即成长)的载体,也是"边缘内化"拼图张力的来源:焊接新块会把旧边缘格变成内部格,曾经的炮位变成内脏位。MVP 若做,只需最小闭环:拼块入池 → 焊接 → 射界/邻接重算。

## 任务

- [ ] 甲板拼块卡入三选一池(权重占位 15%,恢复 GDD 池结构),形状:1×2 / L 形 / 2×2 / T 形
- [ ] 焊接模式:时停;拼块吸附到船体任意外边缘,合法位置高亮;确认即焊死(局内不可拆、不可挪)
- [ ] 焊接后全量重算:暴露边 → 边缘/内部格 → 射界(04)→ 邻接(06)
- [ ] 边缘内化:被围死的武器塔进入离线态(灰显、不开火,03 已预留状态机)
- [ ] 转向惩罚:每格 -1°/s(联 02 参数系统)
- [ ] 受击判定体保持不变(09 已定);敌人蹭外圈甲板出火花不掉血
- [ ] 船体渲染随占用格集合更新轮廓(带焊缝感的简单描边即可)

## 验收标准

- [ ] 故意用 2×2 把一门在线塔围死 → 塔即时灰显停火;Tab 视图射界消失
- [ ] 焊接后转向速率下降可测(数值面板)
- [ ] 焊接后船形剪影明显变化(P3 的最小可见性)
