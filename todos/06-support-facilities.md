# 06 · 支援设施与邻接协同

- 优先级:P1
- 依赖:03, 05
- GDD 参考:§4.3 邻接协同、§5.3 支援设施

## 背景

支援设施对**正交相邻**格生效(不含斜角),效果连线所见即所得。注意:GDD §4.3 说 MVP 只实装弹药库、验证读得懂再加,§5.3 又标 4 种 ✅ —— 按 **4 种全做、弹药库先行**执行:先做弹药库+连线可视化并自测可读性,再补其余三种。

## 任务

- [ ] 邻接 buff 系统:正交四邻判定;放置/移除时即时重算;buff 来源可叠加
- [ ] 甲板上邻接效果连线/图标可视化(生效中的连线常显或悬停显示)
- [ ] 4 种设施:

| 设施 | 效果 |
|---|---|
| 弹药库 | 相邻弹药系塔:射速 +25%,装填时间 -30% |
| 散热器 | 相邻过热系塔:过热上限 +50% |
| 电容组 | 相邻充能系塔:充能速度 +30% |
| 装甲舱 | 船体 HP +15;所在舷受撞伤害 -20%(联 09 舷向判定) |

- [ ] 节流类型不匹配时无效果(且 UI 不画连线,避免误导)

## 验收标准

- [ ] 弹药库放在机炮旁,射速/装填变化可实测(数值面板或 DPS 计数验证)
- [ ] 连线只出现在"真实生效"的配对上
- [ ] 装甲舱的 HP 加成随放置即时生效、拆除即时移除(MVP 无拆除,预留)
