# 09 · 结算战报、解锁展示与胜利终幕

- 优先级：P1 — 完整玩家旅程的最后一段
- 依赖：02、03
- 涉及：`ui/gameOver.ts`、`ui/victoryEpilogue.ts`、上传结果提示、相关测试

## 任务

- [ ] 迁移结果标题与注释：Boss 击破、船体解体、未知结果码。
- [ ] 迁移结算统计：存活时间、击杀数量、航段进度、Boss 击杀时间。
- [ ] `summaryText` 不再返回按中文对齐的 `white-space: pre` 文本块；优先改成结构化 label/value 行，英文无需靠空格排版。
- [ ] 迁移武器战报：标题、峰值 DPS、武器名称、伤害数值；武器名走内容 presenter。
- [ ] 迁移新解锁提示、图鉴分类、未解锁标记与内容解锁计数。
- [ ] 精英解锁条目由稳定 ID 组合本地化名称，不在代码里拼“某某精英”的中文词序。
- [ ] 迁移按钮与上传状态：再来一局、同种子重试、返回标题、上传中、已上传、失败原因、确认战报进入终幕。
- [ ] 上传后端返回的内部错误不能直接作为任意 HTML；客户端把已知结果映射到本地化 key，未知错误显示通用失败和可诊断码。
- [ ] 迁移胜利终幕的 aria-label、图片 alt、眉题、标题、正文、下一航行提示和返回操作。
- [ ] `refreshLocale()`：
      - 结算卡打开时使用最近一次 `RunSummary` 重画，不重新评估进度或上传日志
      - 上传中状态保留，完成后按当前语言显示结果
      - 胜利终幕打开时只改文字，不重新播放/重置终幕流程
- [ ] 结果/摘要/图鉴纯函数改为 locale-aware presenter，并分别覆盖中英文测试。

## 验收标准

- [ ] 英文玩家从失败结算可完成重开、同种子重试、回标题、上传日志。
- [ ] 英文玩家从胜利结算可进入完整英文终幕并返回主菜单。
- [ ] 中英文下 `RunSummary`、newUnlocks、weaponReport、pendingLog 完全相同，只改变展示。
- [ ] 切换语言不重复上传、不重复解锁、不触发 restart/title 回调。
- [ ] 结算卡在英文长文案下按钮仍在视口内，统计行和值不挤压错位。

## 口径说明与交接

- 叙事文本允许意译，优先保留语气和世界观，不要求逐字对应中文。
- `STARWRECK`、Boss、DPS 等专名是否翻译由术语表统一决定，不能每个界面各自处理。
