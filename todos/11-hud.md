# 11 · HUD 与威胁罗盘

- 优先级:P1
- 依赖:08, 09, 10
- GDD 参考:§11 UI/UX、§12 可读性规范

## 背景

威胁罗盘是舷向游戏的关键信息:玩家需要不看小地图就知道主压来自哪个方向、该把哪面舷转过去。战斗中甲板走简化渲染,细节留给时停放大视图。

## 任务

- [ ] HUD 常驻元素:船体 HP 条、残骸/升级进度条、局内计时器、航段进度(替代 GDD 的星区进度)
- [ ] **威胁罗盘**:屏幕边缘的主压方向箭头 + 强度表现(怪流密度→箭头粗细/亮度),常驻;数据来自 08 的出怪器实时统计
- [ ] 战斗中甲板简化渲染:塔只显示色块 + 朝向 + 开火闪光;支援设施仅色块(细节在 Tab 射界视图与时停放置视图)
- [ ] 升级三选一卡片 UI(名称/图标/一句话描述/当前等级)
- [ ] 敌我配色落地检查:敌红紫暖色 / 船冷色,色盲模拟工具过一遍

## 验收标准

- [ ] 盲测口头验证:新玩家不看说明能指出"怪主要从哪边来"
- [ ] 1000 敌同屏时 HUD 仍可读,无关键信息被遮挡
- [ ] 全部 HUD 元素在时停放置态正确隐藏/淡出,不与放大甲板抢焦点
