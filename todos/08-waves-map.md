# 08 · 波次脚本与单局地图

- 优先级:P1
- 依赖:02, 07
- GDD 参考:§6.3 波次语法、§9 局结构(裁剪为单地图)、§2.3(裁剪)

## 背景

MVP 的"一张地图"= 一个开阔太空战场 + 一串首尾相接的航段脚本,替代 GDD 的星图/节点结构。波次语法保留:`主压方向流(持续) + 侧压事件(定时)`,主压方向随航段缓慢旋转,让"最优舷"持续漂移。

## 任务

- [ ] 波次脚本格式(JSON/TS 配置):每航段声明时长、主压方向起止角(如 0°→120°)、出怪流(种类/速率/随时间的密度曲线)、定时侧压事件(方向 + 怪组合)
- [ ] 出怪器:在主压方向的屏幕外环形区生成,方向随脚本插值旋转
- [ ] 精英插入接口预留(MVP 不实装精英)
- [ ] 单局结构:4 个航段脚本 × 每段 90–180s,总时长约 8–10 分钟
- [ ] 胜负流程:脚本走完 = 胜利结算;HP 归零 = 失败结算(联 09);结算界面显示存活时间/击杀数,一键重开
- [ ] (可选)结算界面截取最终船形剪影(P3 传播素材的最小雏形)
- [ ] 出怪使用全局种子 RNG(联 01),同 seed 同波次

## 验收标准

- [ ] 主压方向的旋转能通过威胁罗盘读出(联 11),玩家被迫持续微调航向而非固定角度挂机
- [ ] 同 seed 两局出怪序列一致
- [ ] 一局从开始到胜利/失败/重开全流程无需刷新页面
