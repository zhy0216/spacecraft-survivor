# 03 · 甲板网格与放置规则

- 优先级:P0
- 依赖:01
- GDD 参考:§4.1 格子规则、§4.5 战斗中放置规则、§8(T0 拾荒艇)

## 背景

甲板 = 正交网格,唯一需要记住的规则:**边缘格开火,内部格供能**。MVP 只有 T0 拾荒艇的初始 3×4 甲板(10 个边缘格 + 2 个内部格)。

## 任务

- [x] 3×4 甲板数据模型;格状态:空 / 武器塔 / 支援设施
- [x] 暴露边计算:边缘格(≥1 条边暴露)、内部格(四面被围)、角落格(2 条暴露边)——按占用格集合动态推导,不写死(12 扩建复用)
- [x] 放置合法性:武器塔仅限边缘格;支援设施任意空格(内部格只能放支援)
- [x] 放置交互:合法格高亮,非法放置拒绝并提示 —— 灰盒入口 `src/ui/placement.ts`
- [x] 战斗规则:新塔只能放进**空格**;已放置的塔不可移动、不可出售(MVP 无船坞,此即全部规则)
      —— 实现方式是 `sim/deck.ts` **根本不提供**拆除/移动/出售 API
- [x] 塔"离线"状态机预留:格子失去暴露边 → 塔灰显、不开火(MVP 无扩建不会触发,12 需要)

## 验收标准

- [x] 暴露边/边缘/内部/角落判定有单元测试,含非矩形占用集合的用例
      —— L 形 / U 形凹口 / 3×3 带洞 / 5×5 挖洞 / 单列 1×4 / 1×1
- [x] 内部格放武器塔被拒绝;边缘格放支援设施允许
- [x] 甲板渲染与船体一同旋转,格子世界坐标随船变换正确 —— 几何全画在船体局部空间,
      容器每帧只吃插值位姿,"一同旋转"由结构保证;sim 侧 `cellWorldPos ↔ cellIndexAtWorld`
      在 5 组位姿下 12 格往返一致有单测。**配色好不好看仍需真人看一眼**

## 口径说明与交接

- **角落格收紧为"恰 2 条暴露边且两条正交"**:按字面"2 条暴露边"实现的话,1 格宽甲板的每个
  中段都会算角落格,04 号求两条法线的角平分线会退化(对边法线相加为零向量)。
- **格边长不写死**:`deckCellSize() = min(shipLength/4, shipWidth/3) ≈ 37.33`(较小轴是船宽)。
- **04(射界)要用的 API**:`cellWorldPos(At)` 取格心世界坐标、`edgeWorldNormal(edge, heading)`
  取暴露边法线(= heading + 局部角);`cell.exposed` 是四位掩码,`exposedCount` 是暴露边数。
  局部约定:row 0 = 船头行、col 0 = 左舷,船头局部 +X。
- **10(三选一放置流)**:`ui/placement.ts` 是临时灰盒入口(B 开关 / 1 武器 / 2 支援 / 左键放置),
  10 号的"时停 → 甲板放大 → 拖放"会整套取代它。`World.place()` 是全仓唯一放置入口。
