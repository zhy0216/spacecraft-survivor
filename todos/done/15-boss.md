# 15 · Boss 收尾(简单版 → 镜像巨舰)

- 优先级:P1 — 现在打完第 4 段直接 RESULT_WIN,8 分钟没有高潮;先给收尾高潮,镜像巨舰放第二阶段
- 依赖:08(波次运行器)、02(舰船移动)、09(受击模型);与 16 联动:Boss 必掉星币
- GDD 参考:§6.6 星区 Boss:封锁线巨舰(镜像设计)、§9 局结构

## 背景

评审结论:一局 8 分钟,波次脚本走完即 `RESULT_WIN`(world.ts:808),"胜利"只是一个文本,
没有与之匹配的高潮时刻。Boss 是割草游戏"收尾一口"的标配。本作 GDD 的 Boss 设计非常
契合核心卖点——**封锁线巨舰有自己的甲板和塔组,舷向规则与玩家完全相同,打法是航入
射界死角、逐格拆塔**(攻守互换,规则一套)。但这是大工程,分两步:

- **T1(本 issue 最小闭环)**:简单 Boss —— 巨型个体 + 召唤/冲锋行为,活过它才算赢
- **T2(后续独立 issue)**:封锁线巨舰 —— 敌方甲板 + 塔组 + 部位破坏 + 射界可视化

## 任务(T1)

- [ ] 新建 `src/sim/boss.ts`(或扩 enemy.ts):Boss 个体 = 放大的四型之一 + 专属行为
      (周期性召唤蜂群 + 冲锋,复用现有三原语 seek/strafe/charge)
- [ ] 波次脚本接入:第 4 段结束后进入 Boss 段;胜利条件从"wave.done"改为"Boss 击杀"
      (world.ts:808 的 RESULT_WIN 判定点改挂在 Boss 上)
- [ ] Boss 血条 UI(HUD 层,常驻直到击杀);Boss 受击反馈复用 09 的撞击模型(大质量,撞击伤害更高)
- [ ] Boss 必掉星币(16 落地前给大额残骸)
- [ ] 击败 Boss 的结算:胜利界面 + 船形剪影(已有底座) + 本局统计(Boss 击杀时间等)
- [ ] 战斗音乐/音效挂钩(13 音频:Boss 主题或变奏,出场提示音)

## 验收标准(T1)

- [ ] 击杀 Boss 才胜利;未击杀前波次走完不算赢(失败优先口径不变)
- [ ] Boss 的行为肉眼可读:冲锋有前摇、召唤有预告(与精英预警共用提示通道)
- [ ] Boss 战不破坏确定性:同 seed 同操作,召唤的怪与 Boss 行为逐帧可复现
- [ ] 大质量 Boss 撞击不越过受击模型的口径(固定判定体 + 四舷受击,09 已有)

## T2(封锁线巨舰,另立 issue)

- 敌方甲板 + 塔组:用同一套 deck/turret 逻辑反挂到 Boss 上(天然复用 03/04/05)
- 部位破坏:拆塔 → 对应射界消失;观察射界扇形、航入死角(复用 Tab 射界可视化)
- 三个星区 Boss 甲板布局递进(直线舷 → 环形舷 → 活体甲板) —— 当前单地图 MVP 只做第一个

## 口径说明与交接

- **胜利判定只挪一处**:`settleOutcome` 的 `wave.done` 分支改成"wave.done 且 boss 已击杀",
  别在多个地方散布胜利条件。
- **Boss 也是池对象**:与敌人同池或独立池,不 new 常量对象(铁律 3 零运行期分配)。
- **T1 不做部位破坏**:先验证"大个体 + 召唤"的 Boss 战是否够爽、节奏对不对,
  镜像甲板那套大机制等 T1 盲测后再立项。
