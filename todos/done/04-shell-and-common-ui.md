# 04 · 标题、设置、暂停与通用 UI 文案

- 优先级：P1 — 最短路径打通“首次进入 → 选择语言 → 开始游戏”
- 依赖：01、02
- 涉及：`titleScreen.ts`、`settingsMenu.ts`、`settings.ts`、`pauseMenu.ts`、`main.ts`、`index.html`

## 任务

- [ ] 迁移标题页：品牌副标题、继续、开始新航行、放弃存档确认、设置、图鉴、键位提示。
- [ ] 把 `continueLineText` 改成完整句子翻译，传入 segment、duration、kills、hp；允许英文调整字段顺序。
- [ ] 把 `newRunLabel` 改为按状态选择 key，而不是在函数里返回硬编码中文。
- [ ] 迁移设置页：标题、主音量、声音、震屏、伤害飘字、击杀顿帧、开关值、震屏档位、返回、恢复默认、自动保存提示。
- [ ] 语言选项自身使用固定自称：`简体中文`、`English`；“自动”及系统语言说明走翻译。
- [ ] 迁移暂停页：暂停标题、继续、换种子重开、同种子重试、保存退出、失败提示、设置、声音状态与键位表。
- [ ] 迁移 `main.ts` 玩家提示：上传错误、I 键提示、磁吸风暴、Boss/补给横幅。
- [ ] 页面 `<title>` 和品牌副标题进入资源；`STARWRECK` 产品名保持不翻译。
- [ ] 为 `titleScreen`、`settingsMenu`、`pauseMenu` 增加 `refreshLocale()`；刷新时保留：
      - 标题页是否处于放弃存档二段确认
      - 设置页当前可见性
      - 暂停状态与存档失败状态
- [ ] 行为测试不要再通过中文按钮文本决定点击哪个按钮；给动作按钮增加稳定 `data-action`，或按结构/句柄查找。
- [ ] 中文源文案尽量保持现状，避免 i18n 提交顺带改产品语气。

## 验收标准

- [ ] 新玩家可以只通过英文界面完成“开始 → 暂停 → 设置语言 → 返回 → 保存退出 → 继续”。
- [ ] 有存档时的有损确认在两种语言下都明确表达“会放弃当前存档”。
- [ ] 切换语言时按钮主次、confirming 状态和暂停状态不变。
- [ ] 标题/暂停已有单测分别在 `zh-CN`、`en` 下覆盖主要状态。
- [ ] 这些文件的玩家可见代码不再含硬编码中文。

## 口径说明与交接

- `Esc`、`Enter`、`Tab` 等键位 token 与动作文本分开：键名可复用，句子整体仍由翻译决定。
- 不翻译 URL 参数、seed、错误码等开发标识，只翻译其周围的人类说明。
