# 16 · 星币与三选一重摇

- 优先级:P1 — 标准肉鸽决策点;与 14(精英掉落)、15(Boss 掉落)形成掉落闭环
- 依赖:10(经济系统)、14*(精英掉星币);UI 依赖 ui/upgradeFlow
- GDD 参考:§7「星币:精英/事件/Boss 掉落,用于商店购卡、船坞进化费、重摇」、
  「每次升级可花 10 星币重摇一次」

## 背景

当前经济只有残骸一种货币(10 号 issue),升级三选一只有"选 / 跳过(付 15 手续费)"。
GDD 的第二货币"星币"及其第一消费点"重摇"完全缺席——三选一抽到两张废卡时只能
硬选或付手续费,没有"花小钱换一手牌"的取舍。星币同时是精英(14)、Boss(15)掉落的
归宿,是让"稀有怪掉好东西"闭环成立的前提。

## 任务

- [ ] `sim/economy.ts` 加星币账目:world 持 starCoins 字段(与 scrap 同口径:确定性、
      进 checksum 与否待定 —— 若只影响 UI 和消费,不进 checksum,与 maxHp 同口径)
- [ ] 三选一界面加「重摇」按钮:10 星币/次,重掷三个候选(走同一 rng,序列推进
      由玩家操作决定,天然确定性);星币不足时按钮置灰
- [ ] 重摇后的候选同样走 optionHasLegalPlacement 过滤(不会出现放不下的卡)
- [ ] 星币来源接线:精英必掉(14 完成后)、Boss 必掉(15 完成后);MVP 内无商店,
      星币消费点暂时只有重摇(够用)
- [ ] 星币入 HUD:与残骸条并列的独立读数
- [ ] 重摇次数限制(可选):每级最多 1 次,防止"刷到天牌才停"

## 验收标准

- [ ] 10 星币重摇:扣费 → 三个候选全部替换(可能与原候选重复 —— 与 GDD 语义一致,不额外去重)
- [ ] 星币不足时按钮不可点;跳过按钮仍可用(手续费口径不变)
- [ ] 同 seed 同操作序列,重摇消耗的 rng 次数与结果逐位可复现(测试用例钉住)
- [ ] 精英/Boss 掉落星币到账,且不影响出怪随机序列

## 口径说明与交接

- **rng 消耗口径(重要)**:重摇 = 玩家主动行为,允许消耗 rng;但每次重摇必须消耗
  **固定次数**(与 rollUpgradeOffer 相同的 2×UPGRADE_CHOICE_COUNT),不能按池大小浮动,
  否则同 seed 序列依赖重摇时机,平衡调整会漂。
- **星币与 checksum**:如果星币只影响 UI 与消费、不影响任何 sim 判定,按 maxHp 的先例
  不进 checksum;一旦有"星币 ≥ X 触发某行为"的规则,必须进。
- **与跳过的关系**:跳过退残骸(15)、重摇花星币(10),两条出口各管各的,不互相抵扣。
