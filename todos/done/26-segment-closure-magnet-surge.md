# 26 · 段落收束仪式 + 磁吸涌

- 优先级:P1 — 节奏方案 P3 + P4a:章节感与犒赏感,信标时代的重新解读
- 依赖:无(25 号环阵的退潮窗会来接磁吸涌,松耦合)
- 来源:节奏方案 P3/P4;《玩法创新与改进探索》§七 #8

## 背景

节奏诊断第 5/6 条:正向节拍全在菜单里、换段收束生硬。原 P3 方案("停止出怪 → 横幅 →
磁吸 → 再开面板")写于商店还是自动弹面板的时代;信标改版后段边界**不再停顿**
(`stopAtSegmentBoundary = false`),战斗连续流动——所以收束仪式要重新解读:

- **横幅**:跨段那一帧打出「航段 N 肃清 · 补给信标已投放」,把已经存在的信标警报音
  从"一声不明所以的响"升级成有词有据的段落节拍;
- **磁吸涌**:跨段与精英死亡两个时刻,给几秒全场磁吸——"扛过一波立刻全进账"的犒赏
  实体,也正好是磁吸半径收窄(240→80)后一直缺的波谷任务补偿。

## 任务

- [ ] **sim 状态**:World 加 `magnetSurgeTime: number`(秒,0 = 无涌);每帧递减。
      `data/economy.ts` 加 `MAGNET_SURGE_SEGMENT = 2.5` / `MAGNET_SURGE_ELITE = 2.0` /
      `MAGNET_SURGE_RADIUS_MUL = 25`(全部占位待调,25 × 80 = 2000 ≈ 覆盖到弃置半径,
      即"全场")
- [ ] **两个置位点**:① 跨段那一帧(`world.ts:1047-1049`,spawnShopBeacon 同帧)
      `magnetSurgeTime = MAGNET_SURGE_SEGMENT`;② 精英死亡(`world.ts:1392`
      eliteKills++ 处)`magnetSurgeTime = max(现值, MAGNET_SURGE_ELITE)`——取 max 不叠加,
      连杀精英不把涌抻成常态
- [ ] **生效点**:`world.ts:1111` 的 magnetMul 连乘链尾部,涌期间再乘
      `MAGNET_SURGE_RADIUS_MUL`(与磁力协议/磁力干扰同一条链:一律连乘,涌的倍率
      大到干扰减半也罩全场,不必开例外)。锁定机制(drop.ts 的"进过半径就永不放手")
      原样吃这个半径——涌结束后已锁定的照飞,这正是想要的"哗——全进账"
- [ ] **横幅**:hud 加 `showBanner(text, seconds)`(屏中上浅色大字,时停跟随淡出,
      与解锁 toast 分通道——横幅是段落信息,不排队);main.ts 在 `onShopBeacon` 回调里
      调它:「航段 N 肃清 · 补给信标已投放」。第 4 段走完进 Boss 不发信标,横幅由
      enterBossPhase 一侧出「封锁线接敌」(纯 UI,同一个 showBanner)
- [ ] **checksum / 存档**:`magnetSurgeTime` 影响捡拾判定 → 进 `checksum()`
      (`world.ts:2295`)字段清单;`runSave` 快照加同名字段,`RUN_SAVE_VERSION` 2→3,
      旧档判废(既有口径,损失半局,可接受)
- [ ] **测试**:跨段帧置位/精英死亡置位取 max;涌期间远处(> 基础半径,< 弃置半径)
      掉落被锁定并收取;涌结束新掉落回基础半径;双世界同操作 checksum 一致;
      runSave v3 round-trip(capture → restore → checksum 逐帧一致);v2 旧档判废;
      economy 长跑升级次数仍落 [12, 15] 窗

## 验收标准

- [ ] 跨段瞬间:横幅 + 警报 + 全场残骸拔地而起飞向船,3 秒内账面明显进账
- [ ] 击杀精英:同款小规模犒赏,不需要跑过去舔包
- [ ] 涌不改变残骸**总量**,只改变到账时机与折半弃置的比例(离场折半回收因涌而减少
      是预期收益,economy 长跑复核总账)
- [ ] `npm run build` + `npm test` 全绿

## 口径说明与交接

- **零 rng**:两个置位点都是确定性时刻,计时器不掷任何随机;弃置折半回收(drop.ts)
  逻辑不动,涌只是让更多掉落在被弃置前锁定。
- **本批唯一升存档版本的 issue**:24 号刻意做成表现层就是为了把 v3 留给这里一次升完。
  若实施顺序调整,谁先动快照谁升 v3,另一个跟进时**不再**升 v4(同批合并进 v3)。
- 横幅与飘字/震屏不同,是信息不是 juice:**不挂**设置页的「飘字/顿帧」开关。
- 「大 burst 清完触发涌」刻意不做:清屏检测要么全场扫要么记账燃尽,复杂度配不上收益;
  环阵(25)突围后的空场由它自己的退潮窗 + 本 issue 的精英涌覆盖足够。
