# 25 · 环阵事件(波次脚本 pattern)

- 优先级:P1 — 节奏方案 P1 首条:让 burst 从"更密"变成"异质",每段有自己的名场面
- 依赖:26*(松耦合:突围后的退潮窗希望接磁吸涌,但不阻塞)
- 来源:节奏方案 P1;《玩法创新与改进探索》§七 #8

## 背景

节奏诊断第 3 条:所有压力同一种质地——全部敌人都是"从屏外环上朝船连续渗入",没有
阵型时刻。VS 的"蝙蝠环"之所以是名场面,是因为机制异质:**罗盘瞬间失效、必须选一个
薄弱扇区集火突围,突围后天然留下空场 = 天然波谷**。

现有 `WaveBurst`(`src/data/waves.ts:69-84`)只有方向流语义(offsetDeg + spreadDeg);
运行器在 `src/sim/waves.ts:406` 附近按 at 触发。本 issue 给 burst 加 pattern 维度,
首批只做环阵(ring);钳击(pincer)按节奏方案原文后置。

## 任务

- [ ] **数据格式**:`data/waves.ts` 加 `BURST_PATTERN_DIRECTIONAL = 0` /
      `BURST_PATTERN_RING = 1`;`WaveBurst` 加必填 `pattern: number`(与 EdictDef 全字段
      显式填写同风格,现有全部 burst 补 `pattern: 0`,**不用可选字段**——省下 `?? 0` 的
      隐式缺省,表一眼可查)
- [ ] **环阵语义**(注释写进类型):N = counts 总和,出生角 = `主压方向 + offsetDeg +
      i/N × 360°` 均布;`spreadDeg` 语义变为**逐只抖动半宽**(环阵建议填 2);
      同帧整组出、不被单帧上限截断(原子事件既有口径)
- [ ] **运行器**:`sim/waves.ts` burst 触发处按 pattern 分派;ring 分支逐只算均布角 +
      抖动。**每只仍恰好消耗 1 次 rng(抖动掷)**,与方向 burst 的消耗数逐字相同;
      World 侧半径/side 两掷不动(每只 3 次总消耗合同不破)
- [ ] **预警**:`peekNextBurst`(`sim/waves.ts:167-181`)的 out 加 pattern;HUD burst
      预警箭头对 ring 改画**全环脉冲**(罗盘失效感由预警形态先声夺人);渲染层预警
      telegraph 加环形档
- [ ] **编排落表**:段 2 中点首秀(小环,~16 蜂群蛭,前 3-5s 安排静场预告潮汐窗——
      暴风雨前的安静);段 4 加强版(~24 蜂群 + 4 侧掠)。突围后接一个捡拾退潮窗。
      潮汐窗与既有 18 个窗冲突就挪既有窗,**时间加权平均 mul 贴 1(±15%)的不变量不许破**
- [ ] **测试**:环阵角度生成纯函数用例(均布/环回/抖动上限);数据表不变量
      (pattern ∈ {0,1}、counts 长度 = ENEMY_KIND_COUNT 既有钉法沿用);运行器用例
      "ring burst 同帧出 N 只、角度均布";潮汐均值不变量重验;固定 seed 用例重钉

## 验收标准

## 口径说明与交接

- **改脚本 ≠ 改合同**:加 burst 会移动本局 rng 序列与经济总量,waves/economy 的固定
  seed 用例按先例重钉(a231599、潮汐两轮都干过);但"每只恒 3 掷"的消耗合同一个字不变,
  专项用例要把这条钉死,防止 ring 分支少掷/多掷。
- **本批放最后做**:23/27 的数值改动也要重钉经济轨迹,先落它们,环阵最后一次性钉,
  避免同一批用例钉两遍。
- pincer(±90° 双向钳击)刻意不做:等环阵实测"阵型事件"的读感成立再加第二种,
  pattern 字段已经把路留好。
