# 24 · 齐射共振(broadside 时刻复活)

- 优先级:P0 — GDD §2.1"broadside 时刻配专属音效与屏幕反馈"的原始梦想;事件通道现成
- 依赖:无
- 来源:《玩法创新与改进探索》B3;GDD §2.1/§12"每条舷是一个声部"

## 背景

`src/sim/fx.ts` 的 `FireSink.fired(slotIndex)` 注释明写:旧版"单舷 ≥3 塔同帧开火"的
broadside 统计随甲板四舷删除,**签名保留 slotIndex 就是给这件事留的口子**;World 侧
实现在 `src/sim/world.ts:802`,目前只收不记。

8 槽每 45° 一档朝向,**相邻三槽正好张成一面 90° 的"舷"**。把它接上:短窗内相邻三槽
都开过火 → 共振时刻(和弦 + 舷侧闪光)。这给 I 键换位面板第二条决策轴:
**集中一舷换共振,摊开全向换覆盖**——现在换位只有"射界缺口"一个考量。

## 任务

- [ ] **判定(World 侧,纯统计零 rng)**:`world.ts:802` 的 `fired` 落账到
      `lastFiredTick: number[]`(长度 = `WEAPON_SLOT_COUNT`,初值 -1);每次落账后只查
      **包含该槽的三个相邻三元组**(i-2..i / i-1..i+1 / i..i+2,mod 8 环回),
      三槽的 `lastFiredTick` 都落在 `RESONANCE_WINDOW`(0.5s 占位)内即触发;
      触发后 `RESONANCE_COOLDOWN`(4s 占位)内不重触发(冷却计时器)
- [ ] **空槽即断**:三元组里任何一槽 `type < 0` 不成立(空槽不是舷);合成/替换换掉武器
      不清 lastFiredTick(记录的是"这个槽位开过火",不是"这把武器")
- [ ] **表现(v1 只做演出,不加伤害)**:`src/sim/fx.ts` 新增 `FXV_RESONANCE = 9`,
      towerType 字段借放**三元组中心槽下标**(FXV_KILL 借放敌型的同款手法);渲染层按
      `WEAPON_SLOT_FACING[中心槽] + heading` 画一道舷侧弧形闪光(冷色),叠一次轻震屏
      (走既有 trauma 通道,幅度 ≤ 击杀档)
- [ ] **音频**:audio 总线加共振和弦一档(素材缺席时合成兜底:同舷三塔的开火音高叠三度,
      呼应 GDD"单舷多塔齐射音效叠成和声")
- [ ] **测试(Node 直测)**:相邻三槽窗内齐射触发/两槽不触发;7-0-1 环回三元组触发;
      中间夹空槽不触发;窗口过期不触发;冷却期内二次齐射不触发;fx 事件带正确中心槽下标

## 验收标准

- [ ] 三门同型武器换位排到相邻三槽、把那面舷转向敌群,能稳定听到/看到共振;摊开布局则不触发
- [ ] 时停(升级/整备)期间不发声不闪(fx 一次性消费锁既有机制罩住)
- [ ] `world.checksum()` 前后不变(见口径);`npm test` 全绿,新增用例 ≥6 条

## 口径说明与交接

- **v1 刻意做成表现层**:`lastFiredTick` / 共振计时器**不进 checksum、不进 runSave**,
  先例是逐武器 DPS 的 2.5s 一阶平滑(fcc6c1b:"按实际结算量归账,不进 checksum")——
  它们只喂 fx,不参与任何判定。读档后统计清零,代价只是"读档头半秒不共振",可接受。
  好处:本 issue 零存档影响、零重钉。
- **升级路线已想好但本批不做**:若实测后要给共振加真增益(短暂伤害倍率),乘点就在
  `stepTurrets` 传给 `dispatchFire` 的 `damageMul`(`turretFire.ts:67`,法令 damageMul
  已走这条路);那一刻计时器变判定态,进 checksum + 随第二波满层质变一起升存档版本。
  不要在本 issue 里顺手做——增益要和压档(27)后的数值一起调。
- 常量(窗口/冷却)放 `world.ts` 模块级,标「占位待调」;**不进 sim/config.ts**——
  调参面板绑不读取的旋钮是审计点过名的死代码模式,进面板就必须真绑。
