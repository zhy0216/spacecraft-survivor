# 02 · 飞船操控、惯性移动与镜头

- 优先级:P0(全游戏最大风险项,见 GDD §16)
- 依赖:01

## 背景

单摇杆船模型是本作命门:输入 = **期望航向**而非直接位移,走位路径 = 火控指令(P1)。转向速率是全游戏最重要的手感参数。明确不做双摇杆。

## 任务

- [x] 输入映射:WASD → 期望航向向量(有输入才有期望航向)
- [x] 船以**转向速率**追随期望航向,以**加速度**趋近巡航速度;船头始终朝当前航向
- [x] 松手阻尼滑行减速(太空惯性、阻尼偏大)
- [x] 参数全部配置化并支持运行时热调(调参面板或配置文件均可):

| 参数 | 初值 |
|---|---|
| 巡航速度 | 130 px/s |
| 加速度 | 260 px/s² |
| 转向速率 | 100°/s |
| 阻尼 | 松手 1.2s 内停 |

- [x] 镜头:船占屏幕高度约 20%;向航向前方偏移 15%(look-ahead);固定缩放

## 实现要点(供后续 issue 参考)

- `src/sim/ship.ts`:纯逻辑运动模型。顺序钉死为 **存 px/py/pheading → 按 `shipTurnRate`
  上限转船头(不瞬间对齐)→ 推力沿船头方向施加 → 夹到巡航速度**。推力沿船头而非期望航向,
  正是"转船找射界"手感的来源。
- 输入永不进 sim:`World.step(cmd)` 收纯数据 `ShipCommand`,由 `main.ts` 每逻辑帧从
  `Input` 翻译后灌入 —— 换来"同 seed + 同输入序列 → 同一条轨迹",单测可喂脚本化输入。
- 镜头缩放 `= 屏高 × cameraShipHeightFraction / shipLength`,look-ahead 沿插值后的船头方向;
  两者都每帧现读,可热调。船体朝向插值走最短弧 `lerpAngle`,跨 ±π 不甩头。
