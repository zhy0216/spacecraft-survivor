# 04 · 射界系统与可视化

- 优先级:P0
- 依赖:03
- GDD 参考:§4.2 射界

## 背景

射界是 P1(走位即火控)的机制载体:塔装在哪条舷,决定它朝哪射。

## 任务

- [x] 射界计算:塔射界 = 所在格暴露边法线方向 ± 塔弧度/2(随船体朝向旋转)
- [x] 角落格:两条暴露边法线的角平分线为中心,弧度 +60°
- [x] 弧度档位:极窄 30° / 窄 60° / 中 100° / 广 150°(360° 全向接口预留,MVP 不用)
- [x] 目标过滤:塔只索敌/攻击射界扇形 ∩ 射程圆内的目标
- [x] 射界内无目标时炮管归位(回到扇形中心朝向)
- [x] 按住 Tab:战斗中叠加显示所有塔的射界扇形

## 验收标准

- [x] 单元测试:普通边缘格、角落格、多暴露边(凹形轮廓)三类用例的射界中心与范围正确
- [x] Tab 可视化扇形与实际可命中区域一致 —— 扇形几何取自 `cellArc`,渲染层不重算;
      69 万个采样点的几何对拍零失配(边界、跨 ±π、角落加宽、三边外推、全向档全覆盖)。
      **肉眼抽查仍待真人**
- [x] 船旋转时射界实时跟随,无一帧延迟撕裂感 —— 扇形与甲板底板同属 `deckG`、
      吃同一份插值位姿,结构上不可能差一帧

## 口径说明与交接

- **中心角用向量和 `atan2(Σsin, Σcos)`,绝不对角度取平均** —— 跨 ±π 时角度平均会指向反方向
  (单测钉了一个正好差 180° 的用例)。
- **多暴露边外推**:n 条暴露边 → 中心 = 各法线向量和方向,半角 = (arcDeg + (n-1)×60)/2,夹到 π。
  GDD 只写了角落格 +60°,3 条边的 +120° 是外推,12 号扩建才会遇到。
- **对边退化**(1 格宽甲板条):向量和为零,当前取掩码最低位那条边且不加宽。单锥模型表达不了
  双瓣射界,这是刻意取舍 —— 12 号真焊出 1 格宽甲板并往上放塔时需要连放置规则一起重议。
- **05(武器塔)接手时**:
  - `tuning.turretArcDeg / turretRange / turretTurnRate` 是全塔共用的**占位**,要换成每塔一档
    (档位常量在 `src/data/arcs.ts`)。
  - 炮管状态是 `DeckCell.turretOffset`(相对射界中心的偏角,已进 checksum)。它**没有上一帧值**,
    渲染层直接读当前逻辑帧值画炮口线,高刷屏上会有 60Hz 台阶 —— 做开火表现时可顺手补 `pTurretOffset`。
  - `stepTurrets` 每帧只做一次空间哈希查询(半径 = 射程 + 甲板外接半径),全塔共享候选集;
    加逐塔射程时注意别退化成每塔一次查询。
