- 优先级:P1 — 改版记录自注的遗留:"5 层封顶后的复利大概率要往下压",先压两条 ×7.6 重灾区
- 依赖:无(与 23 号同批做,测试一轮钉完)
- 来源:三系统诊断改版记录·遗留一;《玩法创新与改进探索》§七 #2

## 背景

法令乘法档按 `base^level` 连乘(`data/edicts.ts` 叠加口径),两条 ×1.5 单层的在 5 层
处失控:

- **散热协议** `heatMaxMul: 1.5`(`edicts.ts:150`):5 层 = ×7.6 热上限,过热系从
  "点射收支平衡"变成"再也不过热"——把节流机制整个买断,过热系的手感签名(罚贪连射)
  在中后期消失;
- **增幅协议** `xpMul: 1.5`(`edicts.ts:213`):5 层 = ×7.6 经验,升级曲线被单条法令
  拉穿,"一局 12–15 次升级"的经济账保不住。

其余八条(×1.25/×1.3/×1.1 档)5 层复利在 ×2~×3.7 区间,本批**不动**——全表统一压档
要和第二波"满层质变"(B1)一起做,压数值的同时给满层补规则跳变,避免"压完更无聊"
且免得测试重钉两遍。

## 口径说明与交接

- **确定性**:法令数值不碰 rng 合同(拿法令不移序列的结构保证在 upgrade.ts 的恒量掷,
  与数值无关);但增幅改经验轨迹 → 机器人长跑里升级触发时点变化 → 相关固定 seed
  断言按新轨迹重钉。与 23 号同批,一轮钉完。
- **别顺手压别的**:其余八条的压档值已在创新探索 B1 表里给了建议(×1.15/×1.2/×1.08 档),
  但那一刀要和满层质变一起落——单独压档 = 只削不补,法令会显著变无聊。本 issue
  只治"买断节流机制"和"拉穿经济曲线"两处真失衡。
