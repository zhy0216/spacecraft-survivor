# 17 · 空间进化配方(Lv5 + 相邻设施)

- 优先级:P2 — 本作"甲板即 Build"的复利时刻,吃住核心卖点;先于 18 法令
- 依赖:05(塔升级)、06(支援邻接)、10(经济/三选一)
- GDD 参考:§5.5 空间进化(吞噬支援块、腾出格子)、§4.3 邻接协同

## 背景

GDD §5.5 的"空间进化"是甲板系统的复利时刻:满级塔(Lv5)与指定支援设施正交相邻,
在船坞触发进化,结果**吞噬该支援块、腾出一格**。设计意图:"进化释放格子 = 空间系统的
复利时刻;配方要求相邻,所以进化是玩家早在几次升级前就开始的摆位预谋。"
当前 MVP(第一批)做到塔升级 Lv5、支援邻接、船坞重排,但 6 条进化配方全部未实装——
卡池里"叠满级塔"这件事目前的终点只是数值,没有质变。

## 任务

- [ ] 新建 `src/data/evolutions.ts`:配方表(塔型 + 支援型 → 结果塔),与 towers.ts 同风格
      纯数据、可改、可测
- [ ] 配方判定:船坞(refitFlow)里扫描甲板,找"Lv5 塔 + 正交相邻的指定支援"组合,
      满足时金光连线提示(复用邻接连线的可视化)
- [ ] 触发进化:点确认 → 支援格清空(释放格子)→ 塔替换为进化型(新塔型 / 新行为)
- [ ] 6 条配方按 GDD 表落地(数值/机制占位待调):
      - 机炮 + 弹药库 → 加特林要塞(弧度+50°,不再装填)
      - 激光 + 散热器 → 相位切割者(光束穿透,无过热)
      - 磁轨 + 电容组 → 粒子长矛(全屏贯穿,击杀刷新充能)
      - 电弧 + 反应堆 → 特斯拉冠冕(链数翻倍,过热时环船放电)※ 反应堆不在 MVP 表,占位
      - 迫击炮 + 弹药库 → 轨道火雨(三连发 + 燃烧地面)
      - 点防 + 装甲舱 → 荆棘壁垒(击落弹幕反弹回敌方)
- [ ] 进化后塔继续吃邻接(它占的格仍按边缘/内部格判定);被包成内部格时进化的塔
      同样离线(与 03 的 online 状态机一致)
- [ ] 进化不可逆(船坞里不能再拆回),与"塔不可出售"的口径一致

## 验收标准

- [ ] 配方满足时船坞出现可触发提示;点击后支援格释放、塔变为进化型、开火行为变化可测
- [ ] 进化后的塔吃邻接、吃离线判定,不会成为规则的例外
- [ ] 配方不满足时(支援换成别的)绝不触发
- [ ] 确定性:进化不消耗 rng,同 seed 同操作序列逐位不变

## 口径说明与交接

- **配方是"空间关系"不是"卡牌合成"**:判定只看当前甲板布局(Lv5 + 相邻),不做
  物品栏/合成界面,保持 GDD §4.5"船坞是唯一重排时刻"的闸门。
- **反应堆缺口**:GDD 表里电弧配方要反应堆,但反应堆未实装(第二批不做新支援)。
  方案 A:电弧配方暂挂散热器(行为同构);方案 B:本 issue 顺带补反应堆(占位数值)。
  倾向 A,别让配方表卡在未实装的设施上。
- **复杂特效先数值化**:特斯拉冠冕"过热时环船放电"、荆棘壁垒"反弹弹幕"属于新行为,
  可先按数值近似(链数翻倍/弹幕减伤),机制特效留到 M3 打磨。
