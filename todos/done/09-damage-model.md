# 09 · 受击模型与船体 HP

- 优先级:P0
- 依赖:02, 07
- GDD 参考:§4.6 受击模型、§4.4(受击区域不随扩建变大)、§14 数值初稿

## 背景

全局船体 HP(初始 100),无逐格血量、无逐塔摧毁——保持 VS 式的简洁挫败曲线。受击判定体恒定为初始船体核心区,与甲板渲染尺寸解耦(为 12 扩建铺路)。

## 任务

- [x] 全局船体 HP(初始 100),HP 归零触发局终(联 08 失败流程)—— `shipDead` + `onShipDestroyed`
- [x] 受击判定体:固定尺寸核心区,独立于甲板轮廓;敌人蹭到判定体外的甲板只出火花特效、不结算伤害
- [x] 碰撞伤害结算:同一敌人对船的伤害需有结算间隔/无敌帧(GDD 未写,实现必需,防一帧多跳)
- [x] 舷向判定:按接触点相对船头的方位角划分四舷(前/后/左/右)
- [x] 受击反馈:被撞舷闪红 + 该舷塔 0.5s 射速惩罚(轻微;惩罚不可叠加延长,不制造死亡螺旋)
- [x] 装甲舱"所在舷受撞伤害 -20%"的挂钩(联 06)—— `edgeDamageMul` / `hullMaxHp`,MVP 恒返回基准值
- [x] 敌方弹幕伤害接口预留(MVP 无远程敌)—— `World.damageShip(amount, x, y)` 本身就是这个入口

## 验收标准

- [x] 一次接触只结算一次伤害;蜂群贴脸时 HP 下降速率可控可调
      —— 掉血 = 只数 × contactDamage × 倍率 × 口数,有闭式单测;**手感仍待真人试玩**
- [x] 四舷判定正确 —— 四象限 + ±45°/±135° 四条边界逐个钉 + 整周扫描对独立参考实现;
      调试模式(按住 Tab)显示判定体轮廓,被撞舷在甲板上闪红
- [x] 连续受击时射速惩罚保持 0.5s 上限,不无限刷新叠加 —— 规则是「已在惩罚中就不再置」,
      单测走的是「第 0 帧受击 → 0.3s 再受击 → 仍在第一次受击后第 0.5s 结束」

## 口径说明与交接

- **判定体恒定**:`hullCoreHalfExtents` 按 `DECK_ROWS/DECK_COLS` 两个常量算,**不读 deck.rows/cols** ——
  12 号焊多大都不变(GDD §4.4)。判定顺序是先核心区、后甲板轮廓:核心内扣血,轮廓内但核心外只出火花。
- **粗筛半径用 `R + r√2` 而不是 `R + r`**:精筛把矩形按体型两轴各外扩,那个盒子的角
  = hypot(半长+r, 半宽+r) 严格大于 hypot(半长,半宽)+r —— 按 `R + r` 取会把贴着甲板四角进来的
  一小片真擦碰永远筛掉。
- **无敌帧是每只敌人各自的**(`Enemy.hitCd`),不是全船一个:全船一个的话蜂群贴脸只有一只咬得动。
- **`hitBroadside` 对退化点(接触点正压船心)显式返回 BOW**:带符号零下 `atan2(-0, -0) = π` 会
  把它归到船尾,而零的正负完全由 heading 的 cos/sin 符号决定 —— 这是本轮修掉的一个真 bug。
- **broadside 归属**:`sink.fired` 现在对每条暴露边各记一票(角落格算两舷),取代了 05 号临时的
  "取最低位"。3×4 甲板下四舷都凑得满 3 座塔,05 号那个几乎触发不到的齐射反馈现在真能看见。
- **06(支援设施)接手时**:装甲舱的两处挂钩已就位 —— `edgeDamageMul(deck, edge)` 按舷返回受撞
  伤害系数(现恒 1)、`hullMaxHp(deck)` 返回船体 HP 上限(现恒 `tuning.shipHullHp`)。
  `World.place()` 每次放置成功都会重刷 `ship.maxHp`,所以装甲舱的 +15 放下去当场生效。
- **08(局终流程)接手时**:`shipDead` 置位 + `onShipDestroyed` 一次性回调已就位,本轮**不做**
  结算界面/重开/暂停。另注:船沉后 `settleHullDamage` 仍会推火花事件(不再扣血),08 顺手处理。
