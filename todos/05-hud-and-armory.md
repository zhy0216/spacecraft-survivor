# 05 · HUD、舰船背包与战斗常驻读数

- 优先级：P1 — 战斗中可见时间最长，切换语言后必须当帧一致
- 依赖：02、03
- 涉及：`hud.ts`、`armoryPanel.ts`、`shipDiagram.ts`、相关 presenter

## 任务

- [ ] 迁移 HUD 静态标签：船体、升级残骸、加速、航段、精英/Boss、星币、法令、商店、图鉴、火力、击杀、DPS、雷达等。
- [ ] 迁移状态值：就绪、加速中、声音开关、即将来袭、船体受损等。
- [ ] 航段显示从稳定 segment ID 解析本地化名称；`n/N`、全通状态和段内进度由 locale presenter 生成。
- [ ] 迁移主压方向、警告、商店信标、首局键位提示和跨段 banner。
- [ ] 武器/法令徽记、悬停说明统一使用 03 的内容 presenter，不直接读数据表名称。
- [ ] HUD 数字格式化分层：
      - 高频每帧变化的 HP、DPS、计时器避免产生大量临时 formatter
      - 大数值使用缓存的 locale formatter
      - 战斗计时保持紧凑 `m:ss`
      - 单位和句子顺序不直接拼中文
- [ ] 迁移舰船背包：标题、八方向名称、完整飞船、法令区、换位/替换提示、未知型号。
- [ ] `armoryPanel` 与商店共用的 `shipDiagram` 不各存一份翻译状态；两边调用相同的 `refreshLocale()` / presenter。
- [ ] 为 `hud`、`armoryPanel`、`shipDiagram` 增加原地刷新能力。切换语言时：
      - 不重建武器槽、血条、提示节点
      - 不清空 toast/banner 的剩余时间
      - 不改变面板是否打开或战斗 paused 状态
- [ ] 检查 Pixi 层：伤害飘字只有数字，无需翻译；不得为了 i18n 把 locale 引入 renderer/world。

## 验收标准

- [ ] 战斗运行中切换语言，HUD 静态标签和当前动态读数同一帧刷新。
- [ ] 武器背包打开状态下切换语言，槽位、选择态、交换态与射界展示不变。
- [ ] 波段名、法令名、武器名在中英文下来自同一稳定 ID。
- [ ] 60Hz 更新路径不每帧创建新的 i18next 实例或 `Intl.NumberFormat`。
- [ ] HUD/背包相关单测覆盖中英文关键输出，既有数值与几何测试不因文案迁移失去断言。

## 布局检查

- [ ] 英文标签较长时，左上统计列、火力统计和法令 chips 不互相覆盖。
- [ ] `letter-spacing` 只用于品牌/短标签；长英文句子不使用中文式大字距。
- [ ] `white-space: pre` 的多行文本改成结构化行或确保英文不被截断。
