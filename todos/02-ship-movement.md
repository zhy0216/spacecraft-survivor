# 02 · 飞船操控、惯性移动与镜头

- 优先级:P0(全游戏最大风险项,见 GDD §16)
- 依赖:01
- GDD 参考:§3 操控与移动模型、§15 M0 通过标准

## 背景

单摇杆船模型是本作命门:输入 = **期望航向**而非直接位移,走位路径 = 火控指令(P1)。转向速率是全游戏最重要的手感参数。明确不做双摇杆。

## 任务

- [ ] 输入映射:WASD → 期望航向向量(有输入才有期望航向)
- [ ] 船以**转向速率**追随期望航向,以**加速度**趋近巡航速度;船头始终朝当前航向
- [ ] 松手阻尼滑行减速(太空惯性、阻尼偏大)
- [ ] 参数全部配置化并支持运行时热调(调参面板或配置文件均可):

| 参数 | 初值 |
|---|---|
| 巡航速度 | 130 px/s |
| 加速度 | 260 px/s² |
| 转向速率 | 100°/s |
| 阻尼 | 松手 1.2s 内停 |

- [ ] 镜头:船占屏幕高度约 20%;向航向前方偏移 15%(look-ahead);固定缩放

## 验收标准

- [ ] 打出"绕敌群画弧把侧舷对敌"的操作可行且顺手
- [ ] 参数改动无需重启即可体感对比
- [ ] 【M0 门,联合 05/07 最小子集执行】5 人盲测:① 无教学 2 分钟内自发"转船找射界";② 有人做出故意的侧舷齐射并表现出爽感;③ 转向速率没有被抱怨"笨"。三条不全过 → 只调参数,不进后续 issue
