# i18n 开发手册

面向**给 STARWRECK 加文案的人**:支持哪些语言、新文案怎么写、怎么验收。
配套自动门禁见文末「质量门禁」,全部已接进 `npm test`。

## 支持的语言

| 标签 | 语言 | 说明 |
|---|---|---|
| `zh-CN` | 简体中文 | **默认与 fallback**(key shape 的唯一真相源) |
| `en` | English | 与 zh 结构完全一致(编译期由 `DeepRecord` 强校验) |

> `en-XA`(伪语言)是**开发工具**,不是正式语言,见下节。

### 语言设置在哪

标题界面 / 暂停菜单 → **设置 → 语言**。三档循环:`自动 → 简体中文 → English → 自动`。
`自动` = 跟随系统语言(`navigator.languages` 逐个探测,首个命中生效;一个都不命中回落 zh-CN)。
语言偏好存 localStorage(`starwreck.settings.v1` 的 `language` 字段),**只存偏好、不存解析结果**
—— 系统语言以后变了,切回 auto 会重新解析。

### 伪语言:布局压力测试

URL 加 `?locale=pseudo`(**仅 `import.meta.env.DEV` 生效**,生产构建无视),把所有英文文案
原地膨胀约 30–40%(母音翻倍 + `⟦⟧` 包裹),用来暴露截断、溢出、换行错位:
- 插值 `{{var}}`、星号 `★`/乘号 `×`/破折号 `—` 等符号、键位 token(Esc/Enter/Tab/WASD/R/U/I)
  与专名(STARWRECK/Boss/DPS)原样保留;
- 它不写入设置、不进语言列表,`currentLocale()` 仍归一成 `en`,`<html lang>` 读到合法的 `en-XA`;
- 从设置里切一次语言即退出伪语言。

主流程人工验收清单(伪语言下过一遍):**标题按钮不溢出 → HUD 标签不盖数值 → 升级三卡与跳过按钮
可见 → 商店 picker 与背包不打架 → 图鉴滚动区可用 → 结算按钮不被挤出屏幕**。
同一份清单在「桌面 / 窄屏 / 高 DPI」与英文、伪语言下各跑一遍;重点盯
`min-width/max-width`、大 `letter-spacing`、`white-space: pre` 与 `nowrap` 那些固定宽高假设。

## 给玩家加一句新文案:铁律

1. **文案一律走 `t()`**,禁止在 `src/ui/`、`src/main.ts`、presenter 里写硬编码中文
   (AST 门禁直接报红,理由见文末)。极少数例外(键位名、语言自名、console 日志)用**精确
   allowlist**,不许整文件豁免。
2. **两个语言都写**。zh-CN 先加 key,en 在相同路径镜像值 —— 结构必须一字不差
   (key parity 门禁)。content 资源按 **slug** 键控,slug 必须与数据表一一对应。
3. **插值变量两边一致**:一句话用到的 `{{var}}` 在 zh 与 en 里完全相同
   (interpolation parity 门禁);复数 key(以 `_one`/`_other` 结尾)必须有 `{{count}}`。
4. **翻译串只进 `textContent`**,绝不进 `innerHTML`/`insertAdjacentHTML`/`outerHTML`
   (innerHTML 门禁)。原因:i18n 初始化关闭了转义,把翻译拼进 HTML 等于把文案当代码执行。
5. **语言切换后要重画**的界面,实现 `LocaleAware.refreshLocale()` 并在 `main.ts` 里
   `registerLocaleAware(...)` —— 切换成功后由 `refreshAllLocaleAware()` 统一重刷。
6. **`src/sim/`、`src/data/`、`src/core/` 永不 import i18n**(依赖边界门禁)。
   数值 → 玩家文案的映射只允许发生在 `src/ui/presentation/*` 的 presenter 里。
7. 新内容(塔/敌/法令/词缀/航段/解锁/行为)取名:`data/*` 加 `slug`(小写下划线,全表唯一),
   `content` 资源加同名 slug 条目 + 中英两个 name。

## 术语表

| 概念 | 中文 | English | 备注 |
|---|---|---|---|
| 产品名 | STARWRECK 星骸 | STARWRECK | 永不翻译;en 侧只保留 STARWRECK |
| weapon / tower | 武器 | weapon | 代码/数据表写 `tower`,玩家界面写「武器」 |
| edict | 法令 | edict | 三选一与商店里都叫法令 / Edict |
| affix | 词缀 | affix | 精英附加效果 |
| hull | 船体 | hull | 「船体 HP」/ Hull HP |
| scrap | 残骸 | scrap / salvage | 升级成长资源;HUD 里用 Salvage |
| star coin | 星币 | star coin | HUD 印 `★ 星币` / `★ Star Coins`,星号是玩法符号不翻 |
| refit | 整备 | refit | 每两分钟的船坞商店阶段 |
| broadside / firing arc | 射界 | firing arc | GDD 的 broadside;界面统一「射界」 |
| throttle family | 弹药系 / 过热系 / 充能系 | Ammo-fed / Heat-managed / Charge-type | 塔的供弹方式家族 |
| boss | Boss | Boss | 终幕单位,不译 |
| DPS | DPS | DPS | 缩写,不译 |

**大小写规则**:UI 标签用**句首大写**的 sentence case(`Start Voyage`,不是 `START VOYAGE`);
产品名、缩写(STARWRECK/DPS/Boss/HP)与键位(WASD/Esc/Enter)保持原样大写;
装饰眉题(SHIP INVENTORY / DOCK SUPPLY)是全大写,它们是排版元素不是句子。

## 语言包结构

```
src/i18n/
  index.ts          初始化 / t / changeLocale / currentLocale / activatePseudo / currentI18nLanguage
  locale.ts         SUPPORTED_LOCALES / normalizeLocale / resolveLanguage(纯函数)
  types.ts          DeepRecord / LocaleAware
  format.ts         数字 / 百分比 / 时长格式化(locale 感知)
  registry.ts       LocaleAware 注册表与统一重刷
  pseudo.ts         伪语言(en-XA)的纯函数变换
  resources/
    zh-CN/          common(通用词) ui(界面文案) content(内容名) story(叙事)
    en/             镜像,结构由 DeepRecord 保证
```

- `common`:通用动作/状态/错误/键位名(含复数一对 `enemiesLeft_one` / `_other`)。
- `ui`:按界面分段(menu/settings/hud/upgrade/refit/codex/gameOver …),整句翻译。
- `content`:按数据表 slug 键控的内容名(塔/敌/法令/词缀/航段/解锁/行为/Boss)+ presenter 用的效果文案。
- `story`:标题副标、胜利终幕等叙事文本。

## 质量门禁(已接进 `npm test`)

专项可单独跑:`npm run test:i18n`。门禁文件都在 `src/i18n/`,内容包括:

| 门禁 | 文件 | 防什么 |
|---|---|---|
| key / 插值 parity、空值与裸 key | `resource-parity.test.ts` | 两种语言 key 或变量集合漂移、空翻译、值等于 key 路径 |
| content slug ↔ 数据表对齐 | `resource-parity.test.ts` | 资源漏写/多写/打错 slug |
| 硬编码中文(AST 扫描) | `no-hardcoded-text.test.ts` | 玩家可见代码新增中文,注释免疫 |
| innerHTML 守卫 | `no-hardcoded-text.test.ts` | 翻译串被拼进 innerHTML |
| 依赖边界 | `boundary.test.ts` | sim/data/core import i18n |
| 跨语言确定性 | `determinism.test.ts` | 同 seed 两种语言轨迹分叉 |
| 存储回归 | `storage-regression.test.ts` | 语言字段渗进存档、设置键改名、老设置读不出 |
| 伪语言 | `pseudo.test.ts` | 膨胀比例、插值/符号/键位保留、与 i18n 接线 |

## 新文案走查清单(人工,翻译质量)

- 英文**通读完整流程**一遍:标题 → 战斗 → 升级 → 商店 → 图鉴 → 结算 → 终幕,别逐条机翻
  —— 上下文决定冠词、时态与按钮动词是否一致。
- 复数(`1 enemy` vs `3 enemies`)、冠词、单位(`s`/`%`/`/s`/`×`)、标点(`·`/`—`/括号)一致。
- 改中文源文案时,与迁移前的旧文案做 diff,确认没有无意丢句或改玩法说明。

## 口径说明

门禁的目标是**防回归**,不要求翻译:代码注释、测试描述、开发调参面板(`src/ui/debugPanel.ts`)。
对确实需要硬编码中文的极少数情况,用带理由的精确 allowlist(`no-hardcoded-text.test.ts`
顶部),**禁止整文件/整目录豁免**。
